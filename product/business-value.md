# Бизнес-ценность

## Контекст

Tramplin — учебная платформа: курсы, тесты, практика
алгоритмических задач с реальным запуском кода, рекомендации и AI-помощники
для студентов и преподавателей.

## Главная проблема: процесс обучения устарел

Обучение до сих пор строится вокруг презентаций и переписывания лекций в
тетрадь. Студент тратит пару на то, чтобы законспектировать слайды, а не на
то, чтобы понять материал и попробовать его на практике. Конспект в тетради
нельзя запустить, проверить или дополнить: код из лекции переписывается от
руки, ошибки находятся только на зачёте.

Второе: у студента нет полноценной помощи от AI. Если тема непонятна, остаётся
ждать преподавателя или искать ответ самому. Преподаватель тоже готовит
материалы вручную, без AI-инструментов.

Tramplin меняет модель:

| Было | Стало |
| --- | --- |
| Презентация на паре | Интерактивный урок: текст, примеры кода с подсветкой, иллюстрации, доступен в любое время |
| Переписывание лекции в тетрадь | Материал уже есть на платформе, время пары уходит на разбор и практику |
| Код на слайде или в тетради | Код запускается и проверяется на тестах прямо в браузере |
| Вопросы только преподавателю и только на паре | AI-тьютор по материалу урока 24/7 |
| Проверка знаний — раз в семестр, вручную | Тесты и задачи с мгновенной автопроверкой после каждого урока |
| Преподаватель готовит всё вручную | AI-ассистент и AI-агенты через MCP помогают писать уроки, тесты и задачи |

## Проблемы по ролям

| Кто | Проблема сейчас |
| --- | --- |
| Студент | Время пары уходит на конспектирование слайдов; код пишется в тетради и не проверяется; нет AI-помощи, когда тема непонятна; материалы разбросаны, непонятно, что учить дальше. |
| Преподаватель | Лекция читается по слайдам, на практику остаётся мало времени; нет AI-инструментов для подготовки материалов; создание курса, тестов и задач с тест-кейсами занимает много ручного времени; проверка кода и тестов — рутина; трудно видеть прогресс группы. |
| Колледж | Нет единой собственной площадки: контент привязан к сторонним сервисам, нет данных об успеваемости и вовлечённости, сложно масштабировать практико-ориентированное обучение. |

## Ценность

### Для студентов

- **Один вход во всё обучение** — треки → курсы → модули → уроки, тесты и
  практика в одном интерфейсе, прогресс сохраняется.
- **Практика «как на собеседовании»** — алгоритмические задачи с запуском
  кода на нескольких языках, режимы `practice` и `mock_interview` с таймером.
- **Мгновенная обратная связь** — автопроверка тестов и решений, AI-тьютор по
  материалу урока 24/7 (с дневной квотой).
- **Персональная траектория** — рекомендации курсов и задач по прогрессу и
  интересам.

### Для преподавателей

- **Быстрее создавать контент** — редактор уроков с Markdown и превью,
  6 типов вопросов (single, multiple, text, matching, grouping, file).
- **AI-ассистент автора** — предлагает правки урока или задачи: условие,
  ограничения, тест-кейсы, шаблоны кода; преподаватель принимает или
  отклоняет.
- **Наполнение курса агентом через MCP** — внешний AI-агент (Claude Code,
  Codex) под учёткой преподавателя читает курс, валидирует план, показывает
  diff и применяет его идемпотентно. Без прямого доступа к БД.
- **Автопроверка** снимает рутину проверки тестов и кода.

### Для колледжа

- **Собственная платформа и данные** — контент и статистика принадлежат
  колледжу, а не стороннему сервису.
- **Масштабирование практики** — изолированный запуск кода (Piston) и очереди
  (RabbitMQ) позволяют дать практику всем группам без ручной проверки.
- **Привлекательность для абитуриентов и партнёров** — современная
  IT-площадка с AI и подготовкой к техническим собеседованиям.
- **Контролируемая стоимость AI** — квоты на LLM для пользователей и гостей.
- **Надёжность и безопасность** — мониторинг (Prometheus, Loki, Grafana), разделение сервисов.

## Метрики успеха

Целевые значения — гипотезы, уточняются после пилота.

| Метрика | Что показывает | Цель (гипотеза) |
| --- | --- | --- |
| WAU студентов / число зачисленных | Вовлечённость | ≥ 60% |
| Доля завершённых уроков в начатых курсах | Удержание в курсе | ≥ 50% |
| Решённых алгозадач на активного студента в неделю | Объём практики | ≥ 3 |
| Время подготовки урока с тестом преподавателем | Эффективность авторов | −40% к ручному процессу |
| Доля принятых предложений AI-ассистента | Полезность AI для авторов | ≥ 50% |
| Сессий с AI-тьютором на студента в неделю | Использование тьютора | ≥ 1 |
| CTR рекомендаций | Качество рекомендаций | ≥ 10% |
| Доступность API | Надёжность | ≥ 99.5% |

## Не цели (на текущем этапе)

- Замена официальной ведомости и электронного журнала колледжа.
- Монетизация и платные курсы.
- Публичный MOOC для внешних пользователей.
