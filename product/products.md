# Продукты платформы

Tramplin — набор продуктов вокруг одной базы контента и пользователей.
Каждый продукт отвечает на конкретный кейс из [use-cases.md](use-cases.md).

## Роли

| Роль | Кто это |
| --- | --- |
| Гость | Неавторизованный посетитель: каталог, новости, ограниченная квота AI-тьютора. |
| Студент (`student`) | Проходит курсы, тесты и практику. |
| Преподаватель (`teacher`) | Создаёт и публикует контент, задачи и наборы практики. |
| Администратор (`admin`) | Управляет пользователями, ролями и новостями. |
| AI-агент | Внешний агент, действующий через MCP от имени преподавателя. |

## Карта продуктов

| Продукт | Для кого | Что даёт | Где реализовано |
| --- | --- | --- | --- |
| Каталог и обучение | Студент, гость | Треки, курсы, модули, уроки (Markdown, подсветка кода), прогресс | backend, frontend |
| Тесты | Студент | 6 типов вопросов, попытки, учёт в прогрессе | backend, frontend |
| Алгоритмическая практика | Студент | Банк задач, запуск и проверка кода на нескольких языках, наборы практики, режим mock interview | backend (algo worker), infra (Piston, RabbitMQ), frontend |
| Рекомендации | Студент | Подбор курсов и задач по прогрессу и интересам (эмбеддинги, pgvector) | backend (embedding worker) |
| AI-тьютор | Студент, гость | Чат по материалу урока, квоты на запросы | backend, frontend |
| Авторинг | Преподаватель | Редакторы уроков, тестов, задач и наборов практики; публикация с каскадными обновлениями | backend, frontend |
| AI-ассистент автора | Преподаватель | Предлагаемые правки урока или задачи (условие, тесты, шаблоны) | backend, frontend |
| MCP-сервер | AI-агент, преподаватель | OAuth 2.1 + PKCE, чтение курса, validate → preview diff → apply плана | mcp-server |
| Сообщество и новости | Все | Профили пользователей, лента новостей, редакция новостей | backend, frontend |
| Аутентификация | Все | Вход по email-коду, OAuth GitHub и Яндекс, JWT-сессии, связывание аккаунтов | backend |
| Уведомления по email | Все | Доставка писем через очередь с circuit breaker | email-service |
| Администрирование | Администратор | Управление пользователями и ролями | backend, frontend |

## Границы продуктов

- **Backend — единственный владелец данных.** MCP-сервер ходит только через
  публичный authoring API, email-service — только через очередь.
- **Запуск кода изолирован.** Piston не видит базу и доступен только во
  внутренней сети.
- **AI предлагает, человек решает.** Правки ассистента и планы агента
  применяются только после явного подтверждения преподавателя (diff/preview).
- **Планы идемпотентны и не удаляют данные.** Сущности сопоставляются по
  `slug`, повторное применение плана безопасно.
